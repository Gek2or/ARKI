## Загрузить весь проект одним файлом

1. Сохраните из чата файл `ARKI_Project_v1.7_git.bundle`.
2. В этом репозитории выберите **Add file → Upload files**, загрузите файл в корень и подтвердите коммит в `main`.
3. Откройте вкладку **Actions → Import ARKI project**. После успешной проверки GitHub развернёт исходники, выполнит тесты и сохранит их в `main`.

Импорт принимает только подготовленную копию:

```text
SHA-256: ada39d2d62ab33dbab0e8d3eac79c46ea6413027244010b2dc71c1ef529d0fca
Source commit: 4b8d7b0a1d9a214158f69ae0088ebac8cf2f1d61
Source files: 188
```

Файл bundle будет убран из текущей версии дерева после импорта; загрузочный коммит останется в истории Git. Приватность репозитория не меняется.

## Границы этой операции

Импорт исходников не публикует сайт, не подключает прайсы магазинов и не включает синхронизацию семейных данных. Новый Nordic-клиент хранит данные в браузере; закрытый synthetic-only серверный пилот пока работает отдельно. Рабочие базы, ключи и личные данные в подготовленную копию не включены.
