# ARKI — Nordic 2.0 Result Hub

**Репозиторий подготовлен к импорту основной версии ARKI 2.0.**

Главное изменение: после guided onboarding пользователь получает не просто календарь, а **центр недели** — блюда, корзина и Real Cost выбранных магазинов в одном экране. Блюдо можно заменить прямо там; Arki пересчитывает продукты, упаковки, подходящие demo-акции, корзины и стоимость поездки.

## Импорт полного проекта

1. Скачайте из чата `ARKI_Project_v2.0_git.bundle`.
2. Загрузите этот файл в корень `main` через **Add file → Upload files**.
3. Workflow **Import ARKI project** проверит снимок, запустит тесты, импортирует исходники и удалит bundle из рабочей версии дерева.

Ожидаемый снимок:

Source files: 195

## Границы

Это импорт исходников, не production deployment. Живые прайсы K-ryhmä, S-ryhmä и Lidl не подключены; встроенные цены и акции являются демонстрационными. Возможный K-ryhmä pilot — цель, а не подтверждённое партнёрство. Nordic-клиент пока использует browser-local state; закрытый Node/SQLite pilot остаётся отдельным synthetic-only режимом без автоматической семейной синхронизации.
