# ARKI — Guided Nordic 1.9

**Статус: репозиторий подготовлен к импорту основной версии 1.9.**

ARKI 1.9 продолжает связный первый запуск: **профиль → магазины рядом → дни готовки → бюджет → пищевые предпочтения → техника/время → домашние запасы → готовое меню**. После мастера теперь появляется отдельный экран **«неделя готова»**: блюда, сумма корзины, количество сравниваемых магазинов и текущий лучший вариант с быстрым переходом к календарю или сравнению магазинов.

## Загрузить весь проект одним файлом

1. Сохраните из чата файл `ARKI_Project_v1.9_git.bundle`.
2. В этом репозитории выберите **Add file → Upload files**, загрузите файл в корень и подтвердите коммит в `main`.
3. Workflow **Import ARKI project** автоматически проверит точный снимок, запустит `npm test` и `npm run test:web`, импортирует исходники и удалит bundle из рабочей версии дерева.

## Границы

Это импорт исходников, не публикация production-сайта. Живые прайсы K-ryhmä, S-ryhmä и Lidl не подключены; встроенные цены являются демонстрационными. Возможный K-ryhmä pilot — цель, а не подтверждённое партнёрство. Nordic-клиент пока хранит данные в браузере, а сохранённый закрытый Node/SQLite пилот остаётся отдельным synthetic-only режимом без автоматической семейной синхронизации.
